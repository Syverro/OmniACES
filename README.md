# OmniACES (Omnibus Allocation, Crew & Equipment Sync)

OmniACES is a modern, web-based depot kiosk management system designed for transport operations. It features real-time running board allocations, click-to-expand driver and bus schedules, and a multi-tenant master gateway.

## Features
- **Clean Access Gate**: Simple Depot Code login for instant kiosk display.
- **Master Backend Access (`SYV`)**: Unlocks the master management portal to provision and edit depot allocations.
- **Click-to-Expand Running Board View**: View driver details, sign-on times, meal breaks, bus specifications, and PDF running sheets.
- **Modern High-Contrast Dark UI**: Designed specifically for depot monitors and coordinator workstations.

## Setup & Deployment
